# Сайт Частного фонда «Ұлан Қалқаны»

Сайт-визитка благотворительного фонда поддержки военнослужащих, ветеранов
боевых действий и семей погибших при исполнении служебного долга.
Астана, Республика Казахстан.

**Живой сайт:** https://ulankalkany.kz
**Код:** https://github.com/Qwerty23q/ulan-qalqany (ветка `main`)

---

## Как обновить сайт

Сайт статический, без базы данных и админки. Обновление — три команды:

```bash
git add -A
git commit -m "что поменяли"
git push
```

Через 1–2 минуты изменения на `ulankalkany.kz`. Ничего больше делать не нужно.
Браузер посетителя может показывать старую копию до 10 минут — это кэш, не ошибка.

**Откатить неудачную правку:**

```bash
git revert HEAD
git push
```

**Посмотреть локально перед публикацией:** двойной клик по `index.html`.

## Частые правки

### Цвета

`assets/css/style.css`, блок `:root` в самом верху. Меняете значение — меняется весь сайт.

| переменная | что это |
|---|---|
| `--ink` | тёмно-синий фон (взят из логотипа) |
| `--gold` | золотой акцент |
| `--gold-2` | золото для текста на светлом фоне (контраст ≥ 4.5:1) |
| `--paper` / `--sand` | светлые фоны, чередуются между секциями |

### Телефон

1. `assets/js/main.js`, строка 6: `var WHATSAPP = '77074102815';`
2. `index.html` — места с `77074102815` и `+7 707 410 28 15`.

### Банковские реквизиты

`index.html`, секция `id="support"`. Значения продублированы в `assets/js/main.js`
в функции кнопки «Скопировать все реквизиты» — правьте оба места.

### Заставка при загрузке

Логотип анимируется ~2,4 секунды.

- длительность — `SPLASH_MS` в `assets/js/main.js`; при изменении поправьте
  и `@keyframes` в `style.css` (блок «ЗАСТАВКА ПРИ ЗАГРУЗКЕ» вверху файла);
- `SPLASH_ONCE_PER_VISIT = true` — показывать один раз за посещение,
  а не при каждой перезагрузке (лучше для поисковой выдачи);
- пропускается тапом или любой клавишей;
- при системной настройке «уменьшить движение» не показывается;
- при отключённом JS всё равно исчезает: её снимает CSS-анимация.

### Галерея фотографий

Секция отключена — фотографий пока нет. В `index.html` найдите `<!-- ── ГАЛЕРЕЯ`,
снимите комментарий с блока `<section id="gallery">`. Фото класть в `assets/img/`,
заменяя `<div class="ph">…</div>` на `<img src="assets/img/фото.jpg" alt="Подпись">`.

## Языки

Русский и казахский лежат рядом в одном файле:

```html
<p class="ru">Русский текст</p>
<p class="kk">Қазақша мәтін</p>
```

Переключатель KZ/RU в шапке скрывает ненужный вариант через CSS.
Выбор запоминается в браузере посетителя.

**Правило: правите русский — правьте и казахский.** Иначе версии разъедутся.

## Инфраструктура

| что | где |
|---|---|
| Хостинг | GitHub Pages, ветка `main`, аккаунт `Qwerty23q` |
| Домен | `ulankalkany.kz`, регистратор **hoster.kz** |
| DNS | там же: `ns1/ns2/ns3.hoster.kz` |
| HTTPS | Let's Encrypt, выпускается и продлевается автоматически |

### DNS-записи (настроены, менять не нужно)

```
ulankalkany.kz.        A       185.199.108.153
ulankalkany.kz.        A       185.199.109.153
ulankalkany.kz.        A       185.199.110.153
ulankalkany.kz.        A       185.199.111.153
www.ulankalkany.kz.    CNAME   qwerty23q.github.io.
```

**Не трогать** — это почта домена, к сайту отношения не имеет:
`MX (10) → mail.ulankalkany.kz` · `mail.ulankalkany.kz. A 89.35.125.9` ·
`TXT v=spf1 …` · три записи `NS`.

### Если сертификат не выпускается

Симптом: сайт открывается по `http://`, но не по `https://`, в настройках
репозитория поле сертификата пустое сутки и больше.

Причина: GitHub проверил домен, пока в DNS ещё были посторонние записи,
получил отказ и больше не перепроверяет. Лечится переподключением домена:

```bash
git rm CNAME && git commit -m "снять домен" && git push
# дождаться сборки, затем:
printf 'ulankalkany.kz' > CNAME
git add CNAME && git commit -m "вернуть домен" && git push
```

Сертификат выпускается в течение минуты после возврата.

## Открытые вопросы

- [ ] **Автопродление домена выключено.** Оплачен до 27.07.2027. Включить в панели
      hoster.kz — иначе через год сайт исчезнет, а домен смогут перехватить.
- [ ] **Письмо учредителя** содержит категории «уволенные в запас» и «семьи погибших»,
      убранные из перечня благополучателей. Нужно решение учредителя: править или оставить.
- [ ] **Казахский текст** прошёл редакторскую правку, но не вычитку носителем.
      Сверить ключевые термины с казахской версией Устава — она первоисточник.
- [ ] **Векторный логотип** (SVG / AI / EPS / PDF) — сейчас PNG 214 px.
      Вектор будет чётче на Retina и в печати.
- [ ] Не хватает для полноты: фотографии, команда фонда с именами и званиями,
      Устав в PDF, e-mail на домене, картинка-превью для мессенджеров (og:image 1200×630).
