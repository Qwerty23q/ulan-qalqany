# Сайт-визитка Частного фонда «Ұлан Қалқаны»

## Как открыть локально
Двойным кликом по `index.html` — откроется в браузере.

## Что где лежит
```
index.html               ← весь текст сайта
assets/css/style.css     ← весь дизайн (цвета — в самом верху, блок :root)
assets/js/main.js        ← переключатель языка, меню, форма
assets/img/logo-mark.png ← знак фонда (щит), прозрачный фон — используется на сайте
assets/img/logo-lockup.png ← полный логотип со шрифтовой частью (для светлых фонов, печати)
assets/img/logo-mark-source.jpg ← исходник из WhatsApp, на сайте не используется
```

## Как поменять цвета
Открыть `assets/css/style.css`, первые 12 строк — блок `:root`.
`--ink` — тёмный фон, `--gold` — акцент. Меняете значение — меняется весь сайт.

## Логотип
`logo-mark.png` вырезан из `logo-lockup.png` — это чистый знак с прозрачным фоном.
В шапке, подвале и в водяных знаках он выводится **белым монохромом**
(`filter: brightness(0) invert(1)` в CSS): синий оригинал на тёмно-синем фоне теряется.

Если появится **векторный** исходник (SVG / AI / EPS / PDF) — дайте его,
заменим PNG на вектор: будет чётче на экранах Retina и в печати.

## Как включить галерею фотографий
Сейчас секция отключена — фото нет. В `index.html` найти `<!-- ── ГАЛЕРЕЯ`,
снять комментарий с блока `<section id="gallery">`.
Фото класть в `assets/img/`, заменяя `<div class="ph">…</div>` на
`<img src="assets/img/фото.jpg" alt="Подпись">`.

## Как поменять номер телефона
1. `assets/js/main.js`, строка 6: `var WHATSAPP = '77074102815';`
2. `index.html` — три места с `77074102815` / `+7 707 410 28 15`.

## Заставка при загрузке
Логотип анимируется ~2,4 секунды, потом заставка уходит.
- длительность — `SPLASH_MS` в `assets/js/main.js` (строка 7);
  если меняете, поправьте и задержки в `@keyframes` в `style.css`
  (блок «ЗАСТАВКА ПРИ ЗАГРУЗКЕ» в самом верху файла);
- `SPLASH_ONCE_PER_VISIT = true` — показывать один раз за посещение,
  а не при каждой перезагрузке;
- заставка пропускается тапом или любой клавишей;
- у кого в системе включено «уменьшить движение» — заставки не будет;
- если JS отключён, заставка всё равно исчезнет: её снимает CSS-анимация.

## Языки
Русский и казахский лежат рядом в одном файле:
`<p class="ru">…</p>` и `<p class="kk">…</p>`.
Переключатель KZ/RU в шапке скрывает ненужный вариант.
Казахский текст прошёл редакторскую правку (терминология сверена с
официальными формулировками РК). Перед публикацией стоит сверить ключевые
термины с казахской версией Устава фонда — она первоисточник.
